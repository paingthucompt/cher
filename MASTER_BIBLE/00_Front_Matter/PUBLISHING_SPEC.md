# Publishing Specification

## Quality Target

`Publishing-grade reference book` with an estimated final length of `350-500 pages`.

## Required Book Features

- Hardcover book layout compatibility
- Professional typography system
- Clickable Table of Contents in PDF
- Page numbers
- Chapter divider pages
- Concept art placeholders
- Character sheet placeholders
- World map placement zones
- Royal symbols placement zone
- Timeline chart sections
- Google Flow ready prompt boxes
- Production notes blocks
- Version history tracking

## Output Standard

The final output is not just a PDF deliverable. It is a studio-ready universe reference system for writers, producers, AI tools, and partners.
