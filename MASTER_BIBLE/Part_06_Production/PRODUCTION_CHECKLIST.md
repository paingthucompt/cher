# Production Checklist

## Before Writing A New Chapter

- Brand Bible exists and is linked.
- Product Feature Mapping exists for prior episodes.
- CTA strategy is assigned.
- Timeline is updated.

## Before Producing An Episode

- Episode production pack exists.
- Prompt package exists.
- Character/location/prop assets are listed.
- Opening and end-card text are locked.
- Target platforms are selected.
- Dialogue is natural spoken Burmese only.
- No English character dialogue unless explicitly justified by story canon.
- QA checks visual consistency, subtitle readability, natural Burmese dialogue, and brand visibility.


## Flow Setup Before Video

- Create character references before episode videos.
- Create location/scene references before episode videos.
- Create prop references before episode videos.
- Only then create the video scene.
- All character dialogue must be natural spoken Burmese.
