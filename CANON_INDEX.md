# Canon Index

ဤဖိုင်သည် SocialAutoUpload Universe အတွက် official canon source of truth ဖြစ်သည်။

## Canon Control Rule

- AI-generated content သည် default အားဖြင့် `Draft` ဖြစ်သည်။
- Human approval ပြီး `CANON_INDEX.md` တွင်ထည့်မှသာ `Canon` ဖြစ်သည်။
- Canon ပြောင်းလဲမှုတိုင်းကို `CHANGELOG.md` နှင့် `VERSION.md` တွင်မှတ်တမ်းတင်ရမည်။
