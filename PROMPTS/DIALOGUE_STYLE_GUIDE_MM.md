# Dialogue Style Guide - မြန်မာစကားပြော

## Core Rule

Prompt တိုင်းတွင် character dialogue ကို မြန်မာဘာသာစကားဖြင့်သာရေးရမည်။ Dialogue သည် တကယ့်အပြင်စကားပြောသလို သဘာဝကျရမည်။

## Voice Direction

| Character Type | Spoken Style |
| --- | --- |
| King / Queen | ရိုသေမှုရှိ၊ တိုတောင်း၊ အာဏာထက်တာဝန်ခံစားမှုပါ |
| Min Thant | တည်ငြိမ်၊ စဉ်းစားပြီးပြော၊ စကားမများ |
| Messenger | မြန်၊ တို၊ အရေးပေါ်ခံစားမှုပါ |
| Archivist | တိကျ၊ မှတ်တမ်းအချက်အလက်ကိုရှင်းပြ |
| U Nanda | နည်းနည်းမပြတ်သား၊ အဓိပ္ပာယ်နှစ်ခွ၊ တိုတောင်း |
| Civilian | ပိုသဘာဝကျ၊ နေ့စဉ်အသုံးများ |

## Examples

### Natural

"စာက ရောက်သင့်တဲ့နေရာ မရောက်ဘူး။ ဒီလမ်းကြောင်းကို ပြန်စစ်ပါ။"

"အရှင်မင်းကြီး... မှတ်တမ်းနံပါတ် မကိုက်ပါဘူး။"

"အဲဒါက အမှားမဟုတ်ဘူး။ တစ်ယောက်ယောက်က ဖျောက်ထားတာ။"

### Too Written

"ဤဖြစ်စဉ်သည် ကျွန်ုပ်တို့၏ ဆက်သွယ်ရေးစနစ်အတွင်း တည်ရှိနေသော အားနည်းချက်များကို ဖော်ပြနေပါသည်။"

## Prompt Instruction Snippet

Use this in every prompt:

`Character dialogue must be natural spoken Burmese only. No English dialogue. No bookish Burmese. Use short, realistic lines with role-appropriate respect words.`
