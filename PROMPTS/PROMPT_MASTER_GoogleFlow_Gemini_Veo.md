# Prompt Master - Google Flow / Gemini / Veo

## Purpose

SocialAutoUpload Universe episode prompts must keep story canon, visual consistency, brand signal, and product metaphor aligned.

## Required Prompt Fields

- Episode ID
- Scene ID
- Runtime target
- Target platform
- Character IDs
- Location IDs
- Prop IDs
- Product Feature ID
- Story metaphor
- Opening brand signal
- Ending CTA
- Camera language
- Lighting
- Dialogue / no-dialogue rule
- Negative constraints

## Opening Brand Signal

`SocialAutoUpload.com Presents`

## End Card

`Powered by SocialAutoUpload.com`

`Post Once. Publish Everywhere.`


## Dialogue Language Lock

All character dialogue must be in natural spoken Burmese.

Do not write English dialogue for characters. Do not write Burmese dialogue with English sentence structure.

Dialogue should sound like real people speaking in Myanmar:

- short lines
- natural pauses
- role-appropriate respect words
- emotional but not theatrical
- no hard-sell product speech inside character dialogue

If a scene has no dialogue, state: `Dialogue: none. Visual storytelling only.`

If a scene has dialogue, include a `မြန်မာ Dialogue` section and write only Burmese lines.
