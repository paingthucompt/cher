# Timeline

ဤဖိုင်သည် SocialAutoUpload Universe continuity အတွက် central timeline ဖြစ်သည်။

## Timeline Rules

- အချိန်နှင့်ဆိုင်သော event အသစ်တိုင်းကို ဤဖိုင်တွင်မှတ်တမ်းတင်ပါ။
- Event တိုင်းတွင် source chapter/episode link ပါရမည်။
- Tentative events ကို `Tentative` ဟု သတ်မှတ်ပြီး canon approval မပြီးမချင်း `Canon` မပြောင်းပါ။
